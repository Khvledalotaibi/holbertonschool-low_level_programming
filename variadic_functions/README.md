
# Variadic Functions

This project practices variadic functions in C.

## 0. Beauty is variable, ugliness is constant

`sum_them_all` returns the sum of its integer arguments.

## 1. Print numbers

`print_numbers` prints its integer arguments separated by the optional separator.

## 2. Print strings

`print_strings` prints its string arguments, using `(nil)` for NULL strings.

## 3. Print anything

`print_all` prints arguments according to the format characters `c`, `i`, `f`, and `s`.
